Phenomenon

A pulse-echo instrument estimates range from return time, but a timing offset or uncertain speed can bias the estimate.

Scientific construction

Echolocation uses emitted sound and reflected signals to infer something about the surroundings. Bats and some other animals use biological sound emission and hearing; sonar instruments transmit acoustic pulses and analyse returns. An active sonar system uses its own transmitted signal, while passive listening does not have a known emission time and cannot simply use the same round-trip formula. Ultrasound has frequency above the usual human hearing range, but its speed still depends on the medium rather than being set by frequency alone.

In the simplest active pulse-echo geometry, transmitter and receiver occupy the same position and a stationary reflector returns a normal pulse. The disturbance travels to the target and back, so range d=vt/2. The measured time must be the elapsed propagation time from emission to return. A clock offset or fixed electronic/transducer delay can add a time τ. If the instrument reports t_obs=τ+2d/v, interpreting all reported time as propagation overestimates range when τ>0. An independently timed reference reflector can calibrate the delay when speed is known.

If both speed and delay are unknown but fixed across measurements, two reference reflectors at known distances give two independent equations. Subtract them to remove the common delay: v=2(d₂−d₁)/(t₂−t₁), provided the distances and times differ and the path is the same kind. Then τ=t₁−2d₁/v. Use an unused reference to test the model, rather than assume all observations follow the calibration. A reference at the same range provides repeatability information but no independent equation for the slope. A negative or physically implausible inferred delay may reveal an inconsistent model or timing reference.

For a known normal route through two layers, the sound travels each segment on both outward and return legs. If a layer of thickness h has speed v₁ and the target lies a further distance x into a second layer of speed v₂, propagation time is 2h/v₁+2x/v₂. Deduct the calibrated instrument delay before solving. A uniform-speed assumption can bias the inferred depth. Interfaces may themselves produce reflections, so identify the actual return path using the stated geometry and independent evidence. This model assumes normal paths and stationary targets; oblique paths, moving reflectors and refraction need additional modelling.

A single monostatic return in a homogeneous medium determines a range, not a unique direction: many targets at the same distance fit the time. For a target restricted to a known line or plane, extra independent range observations may narrow its location; multiple geometric intersections can remain without a side constraint. In a two-sensor problem, draw the locus of each measured range, intersect them, and state which assumed region selects a solution. Build the model

  1. Identify emission time, return path and instrument delay. Why: Range requires the actual acoustic travel time, not raw clock reading.
  2. Calibrate unknown speed/delay with independent known distances or given data. Why: Subtracting independent references removes the common offset.
  3. Compute target range or segmented path under the stated geometry. Why: Return distance contains both outward and inward legs.
  4. Check independent data, physical location and uniqueness. Why: A scalar range constrains a locus; side or additional ranges may be needed.

Misconception and repair

Every return time uniquely identifies a target location, and electronic delay can always be ignored.

Does a single range determine direction? Could a fixed clock offset mimic a farther target?

Calibrate the time model, trace the actual round trip, then test geometric uniqueness with independent information.

Limits

  • Stationary colocated transmitter/receiver and normal same-path reflection for t=2d/v; not passive listening or arbitrary geometry.
  • Common additive delay and unchanged speed for reference calibration; verify unused reference and physical ranges.
  • Layered model assumes known normal path with no mislabelled interface returns; no refraction/multipath unless stated.
  • A range does not give bearing; multiple range intersections or uncertain sound speed may prevent uniqueness.
