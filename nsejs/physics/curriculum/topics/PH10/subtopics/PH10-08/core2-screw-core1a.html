Reasoning requirement

Infer relative conjugate distances from magnification, convert mechanical pitch into travel and test the screen constraint.

Build the scientific model

For a real object and real inverted image made by a thin converging lens, let M=|m|=q/p>0. From 1/F=1/p+1/q, p=F(1+1/M) and q=F(1+M). If a screw advances by pitch a per complete turn and changes the relative object–lens separation, the magnitude of rotations N=|Δp|/a. The screen must follow the conjugate q (relative to lens); a fixed screen is not automatically compatible. State which part moves, use consistent units, and check travel and direction. Worked teaching anchor

For F=50 mm, M changes from 4 to 2: p increases from 62.5 to 75 mm, Δp=12.5 mm. With pitch 0.5 mm/turn this is 25 turns; q changes from 250 to 150 mm, so the relative screen position must also change by −100 mm.

Misconception and repair

Using magnification as a linear mechanical displacement or assuming one fixed screen stays conjugate.

Compute p and q independently from the measured M; translate only Δp via screw pitch and verify Δq.
