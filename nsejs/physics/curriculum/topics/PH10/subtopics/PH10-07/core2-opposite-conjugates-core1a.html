Coincident global image from opposite-side objects

Reasoning requirement

Translate two local lens axes to one laboratory axis, derive the shared-image constraint and reject degenerate solutions.

Build the scientific model

For a converging lens f=F, put the left object at global x=−p and right object at x=+r with p,r>0. Incident directions are opposite. The left-object image coordinate is x_L=Fp/(p−F); the right-object local image v_R=Fr/(r−F), but its global coordinate is x_R=−v_R. If their images coincide at a nonzero common coordinate, Fp/(p−F)=−Fr/(r−F), so 1/p+1/r=2/F and pr=F(p+r)/2. With fixed separation S=p+r, solve z²−Sz+FS/2=0. Physical solutions require S≥2F for real roots, but equality p=r=F gives both images at infinity, not a finite common point. Thus S>2F for distinct positive finite physical distances. One distance is greater than F and the other less; the common point is real for one propagation direction and virtual for the other.

Worked teaching anchor

Let F=5 cm and S=20 cm. Then pr=50 cm², giving p,r=10±5√2 ≈17.07 and 2.93 cm. One left-to-right real image and one right-to-left virtual image can share the same global x. Reversing which object is farther reverses the common global side. Equal local magnitudes are not by themselves proof of co-location.

Misconception and repair

Using the same positive incident axis for both objects or accepting the double root at both focal points as a finite image.

Use local incident directions separately, convert v back to global x, and verify finite denominators and co-location.
