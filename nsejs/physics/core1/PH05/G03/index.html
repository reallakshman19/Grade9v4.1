1 · Predict before solving

Is the depth at which gravity is 25% of surface gravity greater than, less than, or equal to the altitude where gravity is 25% of surface gravity?

2 · Attempt: protect your decisive work

Find the ratio of the depth d to the altitude h at which the acceleration due to gravity has the identical value g = 0.25 g0. Take Earth radius as R.

Consult this subtopic’s Core1A textbook (help exposure tracked)

H1–H3 · Optional ordered support

Only after the first answer has been saved. Supports may orient, but do not count as independent first attempts.

Set up the interior equation g(d) = g0 * (1 - d/R) = 0.25 g0 and solve for d.

Set up the exact exterior equation g(h) = g0 * [R / (R + h)]^2 = 0.25 g0 and solve for h.

Do not use the binomial approximation for h, because h is comparable to R.

3 · Reconstruct after attempting

Shortest defensible route

1. Depth determination: g(d) = g0 * (1 - d/R) = 0.25 g0 ==> 1 - d/R = 0.25 ==> d/R = 0.75 ==> d = 0.75 R. 2. Altitude determination: g(h) = g0 * [R / (R + h)]^2 = 0.25 g0 ==> R / (R + h) = sqrt(0.25) = 0.50 ==> R + h = 2 R ==> h = 1.0 R. 3. Ratio evaluation: d / h = (0.75 R) / (1.0 R) = 0.75 = 3 / 4.

Independent route/check

Use fractional loss: At depth d, fractional loss is 75%, so d = 0.75 R. At altitude h, gravity is 1/4, so radius r = 2 R ==> h = r - R = R. Ratio d/h = 0.75 / 1.0 = 3/4.

4 · Diagnose the first divergence

If you answered d/h = 2, you mistakenly used the small-altitude linear rule d = 2h, which fails completely when gravity drops by 75%.

5 · Repair that step

Remember that d = 2h applies only for minute changes near the surface (h << R). For large changes, the inverse-square curve drops much more gently than linear.

6 · Boundary: new changed condition

What is the ratio d/h when the decrease in gravity is infinitesimal (Delta_g -> 0)?

In the limit h, d << R: Delta_g/g0 = d/R = 2h/R ==> d/h = 2.0. The ratio transitions smoothly from 2.0 at the surface to 0.75 at g = 0.25 g0.
