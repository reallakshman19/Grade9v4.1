### Three distinct outcomes

| Outcome | Meaning |
|---|---|
| **BLOCKED** | Required data/quotation/hash/negative test/changed-item proof is missing or a fail-closed issue was found |
| **EVIDENCE_STRUCTURALLY_GROUNDED** | The declared bytes, excerpts, references and required fault-testing claims are internally consistent; **still academic HOLD** |
| **R01 scoped acceptance + delegated batch receipt** | A genuine independent reviewer has checked the physics, teaching and QRT. The Golden standard must have been accepted by the Owner first. Actual release remains governed by configured deployment/branch permission rules |

**There is no "academic approved" status generated by an author's packet.** An author cannot self-issue an academic reviewer receipt.

### Production activation (one Owner action, then delegated batches)

1. Owner identifies the representative, complete **Core2 + Core1A + Core1B Golden Sample** and obtains a real R00/R01 review.
2. Owner signs the [OWNER-G0 form](REVIEWER_AND_GOLDEN_TEMPLATES.md) for the **single standard**, not each question.
3. Owner/authorized integrator updates \`quality-policy.v1.json\` to \`ACTIVE_AFTER_OWNER_GOLDEN\`, sets \`production_enabled=true\`, pins the exact golden SHA and receipt path, and requests independent review on that policy-only change.
4. Set GitHub branch protection to require **Physics Evidence Gate R2** (in \`.github/workflows/physics-evidence-gate-r2.yml\`), along with full Python and Chromium QA. Restrict policy/validator/reviewer-receipt edits using CODEOWNERS and reviewer permissions.
5. Thereafter, **every changed governed Physics content file and newly changed Core2 question ID needs a grounded author packet**. R00/R01 inspect samples/risk cases per the versioned audit protocol. Neither repeated Owner-per-question approval nor automatic academic self-certification is permitted.

The workflow is present as a proposal; **this repository's policy is not currently active**. A green Pilot workflow must be reported as PILOT, not as evidence that all authors are already constrained. Source authenticity and scientific meaning still require independent human examination: no finite set of automated checks can guarantee that every future lesson is excellent.
